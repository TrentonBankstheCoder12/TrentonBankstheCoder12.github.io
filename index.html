    1. Ledger Service

      • Balanced-entry invariant
      • Overdraft protection

    2. Matching Engine

      TypeScript, Node.js

      A limit order book that matches on best price, then arrival time. It supports market, IOC, fill-or-kill and good-til-cancelled orders, and it powers the live demo on this page.

      • Price-time priority
      • O(1) cancels
      • ~1M orders/sec benchmark
      Code Live demo 19 tests

    3. Fraud Detector

      Python, FastAPI

      Scores card transactions as they stream in against each card's own history, combining explainable rules with an anomaly score, and returns approve, review or decline with reasons.

      • Velocity and impossible-travel rules
      • 86% recall on synthetic fraud
      • Evaluation harness
      Code Walkthrough 47 tests

    4. Auth Service

      TypeScript, Express

      Authentication built to a bank's standard: argon2id password hashing, short-lived access tokens, and refresh tokens that revoke the whole session if one is ever reused.

      • TOTP two-factor (RFC 6238)
      • Refresh-token reuse detection
      • Account lockout
      Code Walkthrough 52 tests
